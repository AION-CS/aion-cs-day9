# UX standards

The interaction, structure and style standards for every CS day live one folder up, in
[`../CLAUDE.md`](../CLAUDE.md), and the content standard in [`../CURRICULUM-GUIDE.md`](../CURRICULUM-GUIDE.md).
Claude Code loads `CLAUDE.md` automatically from any `dayN` folder.

This file used to hold a copy of the older Green IT standards (two routes per day, green accent). That copy
contradicted the CS course (three routes per day, amber/teal/rust palette), so it was replaced by this pointer.
Do not re-add a second copy: change the shared file instead.
